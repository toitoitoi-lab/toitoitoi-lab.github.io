# サイト用 GAS（お問い合わせ・閲覧数・運営者ページ）

toi toi toi のお問い合わせフォーム・閲覧数・運営者ページを動かす Google Apps Script です。
サイト（GitHub Pages）は見た目だけで、記録とパスワードの確認はすべてこの GAS が行います。

```
サイトのフォーム ──送信──▶ GAS ──記録──▶ スプレッドシート（あなたの Google ドライブ）
                               └──通知──▶ あなたの Gmail（中身は入れず「届いた」だけ）
各ページ ──「開かれた」──▶ GAS ──数える──▶ スプレッドシート「閲覧数」
運営者ページ ──パスワード──▶ GAS ──合っていれば件数と閲覧数を返す
```

- パスワードはサイトのどこにも書きません。GAS のスクリプト プロパティにだけ入れます。
- 問い合わせの中身は、スプレッドシート（あなたの Google アカウントでしか開けない）でだけ読みます。運営者ページには件数と日付しか出ません。
- 閲覧数は「日付・ページ・回数」だけを記録します。Cookie や、だれが見たかが分かる情報は使いません。

## 設定のしかた（15分ほど）

### 1. GAS のプロジェクトを作る
1. https://script.google.com を開き「新しいプロジェクト」
2. 左上の「無題のプロジェクト」を「toitoitoi サイト」などに変える
3. `コード.gs` の中身をすべて消し、この `Code.gs` の中身を貼りつけて保存（💾）

### 2. パスワードを決めて登録する
1. 左の歯車（プロジェクトの設定）→ いちばん下の「スクリプト プロパティ」→「スクリプト プロパティを追加」
2. 次を登録して「スクリプト プロパティを保存」

| プロパティ | 値 |
|---|---|
| `ADMIN_PW` | 運営者ページのパスワード。**12文字以上**で、ほかのサービスで使っていないもの |
| `NOTIFY_EMAIL` | （省略可）通知を受けるメール。省略すると、この GAS を作った Google アカウントのアドレス |

### 3. 準備（setup）を1回だけ実行する
1. 左の「エディタ」（`< >`）にもどる
2. 上のツールバーの関数の選択で **setup** を選び「▶ 実行」
3. 「承認が必要です」→ 自分のアカウント →「詳細」→「（安全ではないページ）に移動」→「許可」
   - 自分で作った GAS なので、この表示は正常です
4. 実行ログに「準備ができました：https://docs.google.com/spreadsheets/…」と出れば完了。ドライブに「toi toi toi 問い合わせ・閲覧数」ができています

### 4. ウェブアプリとして公開する
1. 右上「デプロイ」→「新しいデプロイ」→ 種類の歯車で「ウェブアプリ」
2. **次のユーザーとして実行：自分**、**アクセスできるユーザー：全員**
   - 「全員」にしないと、サイトの訪問者がフォームを送れません。パスワードがないと件数も閲覧数も見られないので大丈夫です
3. 「デプロイ」→ 表示された **ウェブアプリの URL**（`…/exec` で終わる）をコピー

### 5. URL をサイトに入れる
`src/data/site.ts` のいちばん下の `BACKEND_URL = ''` の `''` の中に、4 の URL を入れます（Claude に URL を伝えれば入れてもらえます）。
この URL は公開されても問題ありません（パスワードがないと何も読めません）。

### 6. 確かめる
1. サイトの「お問い合わせ」から、テストで1通送る → Gmail に通知が届き、スプレッドシートに1行増える
2. `https://toitoitoi-lab.github.io/kanri/` を開き、パスワードを入れる → 件数と閲覧数が出る
3. テストの行は、スプレッドシートで「対応済み」にするか、行ごと消す

## ふだんの使い方
- **問い合わせに気づく**：運営者ページで「このブラウザで、問い合わせのお知らせを表示する」を選んでおくと、そのブラウザでサイトを開いたとき、操作ボタンに 📩 と未対応の件数が出ます
- **対応したら**：スプレッドシートの「対応状況」を「対応済み」に変える
- **ほかの端末でも見たい**：その端末で運営者ページを開き、パスワードを入れる

## コードを新しくしたとき
コードを貼りかえて保存 →「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」。
（「新しいデプロイ」にすると URL が変わってしまうので注意）

## 困ったとき

| 表示 | 原因と対処 |
|---|---|
| 準備ができていません（setup を実行してください） | 手順 3 をやり直す |
| ADMIN_PW が未設定か、短すぎます | 手順 2。12文字以上にする |
| まちがいが続いたため、15分間ログインできません | パスワードを5回まちがえると止まります。15分待つ |
| ログインの有効期限が切れました | 90日たつと切れます。パスワードを入れ直す |
| パスワードを忘れた | スクリプト プロパティの `ADMIN_PW` を新しく書きかえる |
| 通知メールが来ない | Gmail の迷惑メールを確認。`NOTIFY_EMAIL` を確認 |

## 無料の範囲
Google Apps Script とスプレッドシートは無料で使えます。メール送信は1日100通まで（無料の Google アカウントの場合）、GAS の実行時間にも1日の上限がありますが、個人サイトの問い合わせと閲覧数なら十分に収まります。
