# toi toi toi サイト設計仕様 v0.4

2026-09-27 作成。フォントと表示設定について国内外の研究を調べ直し、v0.1（ダーク案＋Andika）を見直したもの。

---

## 1. 基本方針

**サイトそのものを AT の考え方で作る。**

- 一つの「正解の見た目」を押しつけない。配色・文字の形・大きさ・間隔を、見る人が選べるようにする
- 選んだ設定は覚えておき、どのページでも同じ設定で表示する
- どの設定を選んでも、届く情報は同じにする（別版を作らない）

## 2. 調査で分かったこと

### 海外

- **「子ども向けの字形」が読みやすさを上げる根拠は弱い。** 一階建ての a・g（infant characters）について、Reading大学の Walker & Reynolds が 5〜7歳児で比べたところ、普通の字形でも一階建てでも同じように読めた。
- **「ディスレクシア用フォント」にも効果は確認されていない。** Dyslexie（Kuster ほか 2018、170人以上の児童）、OpenDyslexic（Wery & Diliberto 2017）ともに、読む速さ・正確さは改善せず。子どもの好みと成績も関係がなかった。
- **効果が確認されているのは「間隔」。** 文字の間隔を広げると、ディスレクシアのある子の読みの速さと正確さが上がった（Zorzi ほか 2012, PNAS）。
- **英国ディスレクシア協会（BDA）のスタイルガイド 2023：** サンセリフ体、16〜19px、字間はおよそ文字幅の35%、行間1.5倍、斜体と下線を避ける、真っ白ではなくクリーム色などの背景に濃い文字。
- **ダークモードは「合う人」と「合わない人」がいる。** 光に過敏な人には楽になる一方、乱視の人は明るい文字がにじんで見えやすく（ハレーション）、読み書きの困難がある人には強すぎるコントラストがつらいことがある。選べるようにすることが推奨されている。

### 日本

- **学校の教科書は、あえて学年で字形を変えている。** 光村図書によると、小学校の英語教科書は手書きにきわめて近い字形、中1は手書きに近いゴシック、中2以降で一般的な字形（二階建ての a・g、セリフ付き）に移る。見る文字と書く文字の違いを小さくするため。セリフは漢字の「はね」「はらい」と混同されうるので、早い段階では使わない。
- **UDデジタル教科書体**（モリサワ）は、弱視・ディスレクシアの児童生徒のために、学習指導要領の字形（書写）に合わせて作られた。慶應義塾大学の中野泰志氏、大阪医科薬科大学LDセンターの奥村智人氏の研究で読みやすさが確認されている。欧文は2018年の文部科学省小学校外国語教材の字形に準じている。Windows 10以降に標準で入っている。
- **文化庁「常用漢字表の字体・字形に関する指針」（2016）** は、手書きと印刷の字形の違いは誤りではないと整理している。ただし、字形へのこだわりが強い子にとっては、その違いを受け入れること自体が負担になりうる。

### 字形へのこだわり（自閉スペクトラム症など）について

- 字形へのこだわりそのものを直接扱った研究は、今回の調査では見つからなかった。
- 分かっているのは、①特定の字形が万人に効くという根拠はない、②日本の子どもは学校で「手書きに近い字形」から順に学んでいる、ということ。
- **結論：** 「この字形が正しい」と一つに決めるのではなく、**学校で習う形を選べるようにし、選んだ形を一貫して使う**のが最も安全。

## 3. 表示設定パネル

全ページのヘッダーに「表示設定」ボタンを置く。キーボードだけで操作でき、選んだ設定はブラウザに保存する。

| 項目 | 選択肢 | 初期値 |
|---|---|---|
| 配色 | ダーク／ライト（クリーム色）／ハイコントラスト | ダーク（OSが高コントラストを求めている場合はハイコントラスト） |
| 文字の形 | すっきり（UDゴシック）／学校で習う形（教科書体） | すっきり |
| 文字の大きさ | 標準（18px）／大（21px）／特大（24px） | 標準 |
| 文字の間隔 | 標準／ひろめ | 標準 |

## 4. フォント

どちらのプリセットでも、英字は **Andika**（SIL、OFL）を使う。

- a・g は一階建て（小学校の英語教科書の字形に近い）
- 大文字 I は上下に横線あり（l・1 と区別しやすい）
- **t は跳ねのない形に切り替える**（`font-feature-settings: "cv56" 1`）。Andika は t の跳ねを外す字形を公式に用意している
- l（エル）は標準で跳ねなし

| プリセット | 日本語 | フォールバック |
|---|---|---|
| すっきり | BIZ UDゴシック（モリサワ、OFL） | sans-serif |
| 学校で習う形 | UDデジタル教科書体（端末に入っていれば使う） | Klee One（フォントワークス、OFL）→ serif |

- フォントは Google Fonts から読み込まず、**サイトに同梱する**（OpenType機能を確実に使える／閲覧者の情報が外部に送られない）
- 太さは 400 と 700 のみ（BIZ UDゴシックの最大が700のため）
- 斜体は使わない。英字ラベルの大文字は CSS（text-transform）で表示し、元の文字は小文字にする（読み上げで一文字ずつ読まれるのを防ぐ）
- 英語部分には `lang="en"` を付ける（読み上げの声が英語に切り替わる）

## 5. 配色

コントラスト比は WCAG 2.2 の計算式で確認済み（本文は 4.5 以上が基準）。

### ダーク（初期値）
真っ黒・真っ白は使わない（にじみを抑えるため）。右上から光が差すグラデーションと、うっすらした粒子感を背景に入れる。

| 役割 | 色 | 背景に対する比 |
|---|---|---|
| 背景 | #0B0C0F | — |
| パネル | #14161B | — |
| 本文 | #ECEDE6 | 16.6 |
| 補足文 | #A7ADB3 | 8.6 |
| アクセント（ライム） | #D4FF3A | 16.9 |
| 差し色（紫） | #B3A4FF | 8.3（パネル上） |

※ v0.1 の紫 #7C5CFF はパネル上で 4.38 しかなく、基準を満たしていなかったため変更。

### ライト（クリーム色）
BDA の推奨どおり、真っ白ではなくクリーム色の背景。ライムは文字色にすると読めないため、塗り（ボタンなど）にだけ使い、文字のアクセントは濃いオリーブにする。

| 役割 | 色 | 背景に対する比 |
|---|---|---|
| 背景 | #F4F1E8 | — |
| 本文 | #16181C | 15.7 |
| 補足文 | #4E545A | 6.8 |
| アクセント文字 | #4B5E00 | 6.4 |
| 差し色（紫） | #5A3FD0 | 6.7（パネル上） |

### ハイコントラスト
黒背景・白文字・黄色アクセント（21.0／16.5）。光や粒子の装飾は消す。OSの「コントラストを上げる」設定（prefers-contrast: more）や強制カラーモードのときは自動でこれにする。

### イラスト（2026-09-27 決定：パターンB「塗りの絵本風」）

- 「困りごと」「立場」の入口に、塗りで描いたやわらかいイラストを付ける。角は丸く（カード20px）
- 色はクリーム・コーラル・水色・紫・ライムの5色。背景は困りごとごとに、紫・水色・コーラルの3系統を交互に使う
- 配色設定ごとに色を切り替える
  - ダーク：濃い色の背景に、明るい塗り
  - ライト：淡い色の背景に、少し濃い塗り（ライムは #7FA600 に落とす）
  - ハイコントラスト：塗りを消して、白の線と黄色の強調だけにする
- 線は、その線が乗る面に対して見える色を使う（クリームの上は濃い線、暗い背景の上は明るい線）
- イラストは装飾として扱い、読み上げでは飛ばす。名前と説明は文字で読み上げる

## 6. 構造とアクセシビリティ

- 各ページの先頭に「本文へ移動」「サイトマップへ移動」のスキップリンク（Tabキーで最初に現れる）
- 見出しは h1 → h2 → h3 の順を守る。ランドマーク（header / nav / main / footer）を使う
- キーボードのフォーカス枠は3pxのアクセント色で、どの配色でも見えるようにする
- ボタンやリンクの押せる範囲は48px以上
- 画面上でいちばん小さい文字も16px以上にする（補足文・ラベル・フッターを含む）
- 「困りごと」「立場」の入口には、内容を表すイラストを付ける（装飾扱いにして読み上げでは飛ばし、名前は文字で読み上げる）
- 本文中のリンクには下線を付ける（色だけで区別しない）
- アニメーションは「視差効果を減らす」設定（prefers-reduced-motion）のとき止める
- 目標：JIS X 8341-3:2016 の適合レベルAA。NVDA と VoiceOver で読み上げを確認し、公開前に当事者や先生方に見てもらう

## 7. サイトマップ

v0.1 の「表示モードの切り替え」から、**独立したサイトマップページ**（/sitemap/）に変更する。

- 理由：モードで中身を入れ替えると、通常版と簡易版の内容がずれていきやすい。ページにすれば、URLで共有・ブックマークでき、スクリーンリーダーの人も晴眼者も同じものを使える
- ヘッダーの「サイトマップ」ボタンから1回で行ける。スキップリンクからも行ける
- ナビゲーションと同じデータから自動で作るので、ページを増やしても更新漏れが起きない
- 大項目（サイト全体・困りごと・立場・発信）の下に小項目が線でつながる「木の形」にする。最後の項目で線が止まる（└）ので、まとまりの終わりが見て分かる
- 上部に4つのまとまりへの目次とページ数を置く
- HTMLは入れ子のリスト（大項目のリストの中に小項目のリスト）にし、大項目は見出し（h2）にする。読み上げでも「4項目のリスト → その中に6項目のリスト」と階層が伝わる

## 8. ページ構成（日英共通）

- トップ（困りごとから探す）
- 困りごと別：読む／書く／聞く・見る／伝える／操作する／見通す・整える
- 立場別：先生・支援者の方へ／本人・ご家族の方へ／つくりたい方へ
- 発信：記事一覧・記事ページ（Markdownで更新）／YouTube／note（外部）
- 研修・講演について
- 利用ルール（事前連絡制）／お問い合わせ
- このサイトについて
- サイトマップ
- 英語版（/en/ 以下に同じ構成）

## 9. 未決事項

- 初期配色をダークのままにするか（乱視の人には合わない場合がある。設定ですぐ変えられることを前提にダークを初期値にしている）
- 大文字 I の横線が、実際に教えている形と合っているか（先生方に確認したい）
- 「学校で習う形」の英字を、UDデジタル教科書体の欧文にそろえるか（ウェブで使うには Adobe Fonts などの契約が必要）
